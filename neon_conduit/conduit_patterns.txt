; Neon Conduit - tunnel wall patterns
;
; Each stretch of tunnel (between two outdoor runs) picks one of these at random,
; and paints it in that stretch's colours. The floor is never patterned.
;
;   [name]            starts a pattern
;   key = value       optional settings, before the rows:
;                       scroll   = rows per second the pattern slides towards the
;                                  sled (negative: away from it); default 0
;                       contrast = strong (default) or soft: how far apart the
;                                  pattern's two colours are
;   ##..##..##..      one row per track segment; the rows repeat down the tunnel,
;                     each row the next segment further ahead
;
; A row has 12 characters, one per wall panel, going round the tube as you look
; ahead: from the left wall just above the floor, up over the ceiling, then down
; the right wall to the floor.
;   .     the stretch's dark colour
;   #     its light colour
;   0-9   in between: 0 is dark, 9 is light
;
; Everything after a ; is a comment.
